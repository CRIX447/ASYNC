# Assets

Drop your files here, then register them in `src/config/manifest.js`.

```
textures/   wall.jpg, carpet.jpg, ceiling.jpg   (seamless/tileable, 1024 or 2048)
models/     *.glb                                (Blender: File > Export > glTF 2.0, .glb)
sounds/     *.mp3                                (mp3 or ogg; keep loops seamless)
```

Nothing here is required. Every missing file falls back to a generated
placeholder, so the game runs on a fresh clone.

Free CC0 sources:
- https://ambientcg.com        textures (search "wallpaper", "carpet", "concrete")
- https://polyhaven.com        textures, HDRIs, models
- https://freesound.org        audio (check each file's licence)
