SOUNDS GO IN THIS FOLDER
========================

Format: .mp3 (or .ogg). All optional.

START WITH THESE THREE -- they're 80% of the atmosphere:

    hum.mp3          fluorescent light hum, LOOPING
    footstep.mp3     single step on carpet
    drone.mp3        low dark ambient bed, LOOPING

THEN:

    menu.mp3         main menu music, LOOPING
    click.mp3        flashlight + switch press
    error.mp3        wrong switch order
    pickup.mp3       battery collected
    door.mp3         exit door opening
    heartbeat.mp3    LOOPING, plays below 25% sanity

RANDOM DISTANT NOISES (fire every 20-55s, more often as sanity drops):

    far_thump.mp3
    far_creak.mp3
    far_voice.mp3
    buzz_pop.mp3

LOOPS MUST BE SEAMLESS or you'll hear the join every few seconds.
Audacity:  Effect > Crossfade Loop

Free audio:  https://freesound.org
CHECK THE LICENCE on each file -- some are CC0, some need credit.

Configure in:  src/config/manifest.js
