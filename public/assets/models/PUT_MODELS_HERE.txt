3D MODELS GO IN THIS FOLDER
===========================

    player.glb     the character other players see (rigged + animated)

Plus any scenery props you want to place in levels.

FORMAT: .glb only (binary glTF).
In Blender:  File > Export > glTF 2.0 > Format: "glTF Binary (.glb)"

Free rigged characters:
    https://www.mixamo.com    free Adobe account, rigged + animated
    https://quaternius.com    CC0, already .glb, no conversion needed

To inspect a .glb and see its animation clip names:
    https://gltf-viewer.donmccurdy.com

Configure in:  src/config/manifest.js  (the PLAYER block)

If the model is huge, Mixamo exported in centimetres -> set scale: 0.01
If it faces backwards -> set rotationOffset: Math.PI

No player.glb? You get a capsule. That's a fine thing to ship with.
