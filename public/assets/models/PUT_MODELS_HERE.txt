3D MODELS GO IN THIS FOLDER
===========================

FORMAT: .glb only (binary glTF).
Blender:  File > Export > glTF 2.0 > Format: "glTF Binary (.glb)"

Use these EXACT filenames and they load with zero extra work.

CHARACTERS (rigged + animated, clips named idle / walk / run)
-------------------------------------------------------------
    player.glb        what other players look like
    monster.glb       the thing hunting you

    No file? Player = capsule, monster = tall black silhouette
    with glowing eyes. Both are fine to ship with.

PROPS (static, no rig needed)
-----------------------------
    chair.glb         desk.glb          cabinet.glb
    shelf.glb         boxes.glb         barrel.glb
    pipe.glb          vent.glb          crate.glb
    trolley.glb       sofa.glb          lamp.glb
    computer.glb      filecabinet.glb   generator.glb
    door.glb

Place them from a level file:
    props: [ { model: 'chair', cell: [6,12], rotation: 0.4 } ]

WHERE TO GET THEM
-----------------
    https://www.mixamo.com     rigged + animated characters, free account
    https://quaternius.com     CC0 props and characters, already .glb
    https://polyhaven.com      CC0 models
    https://kenney.nl          CC0 low-poly prop kits

INSPECT A .GLB (see its animation clip names):
    https://gltf-viewer.donmccurdy.com

COMMON PROBLEMS
---------------
    Model is enormous     -> Mixamo exports in cm. Set scale: 0.01
    Model faces backwards -> Set rotationOffset: Math.PI
    Animations don't play -> Open the browser console. Every clip name in
                             your file is logged on load. Match them in the
                             animations block.

All configured in:  src/config/manifest.js
