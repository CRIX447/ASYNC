ASYNC — what to do with this folder
===================================

Everything in here goes into your cloned ASYNC repo folder.

  1. git clone https://github.com/CRIX447/ASYNC.git
  2. cd ASYNC
  3. Copy EVERYTHING from this zip into that folder.
     Say YES when it asks to overwrite README.md and LICENSE.
  4. git add .
     git commit -m "Level 0 prototype"
     git push

IMPORTANT — hidden files
------------------------
.gitignore and the .github folder start with a dot, so your file
browser hides them by default. You MUST copy them too.

  Windows : Explorer > View > tick "Hidden items"
  Mac     : press Cmd + Shift + .

If you miss .gitignore, your first `npm install` will try to commit
about 100 MB of node_modules to GitHub.

Then to play it
---------------
  npm install
  npm run dev          -> http://localhost:5173

  npm run server       (second terminal, for multiplayer)

Full details are in README.md.
